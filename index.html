INTRODUCCIÓN

Imagen Escrita.

Este portafolio reúne los proyectos y ejercicios realizados durante el curso de Imagen Escrita 2026, en el que hemos explorado distintas maneras de construir imágenes mediante el uso de herramientas digitales y lenguajes de programación. A lo largo del curso trabajamos principalmente con p5.js, desarrollando composiciones gráficas a partir de formas, colores, patrones, movimientos e interacciones. Estos ejercicios nos permitieron comprender cómo el código puede convertirse en una herramienta de diseño y expresión visual.

Cada proyecto presenta un proceso de exploración y aprendizaje, desde los primeros dibujos y esquemas hasta la construcción de propuestas visuales mediante programación. Más allá de los resultados finales, este archivo busca mostrar las decisiones, las pruebas y los conocimientos adquiridos durante cada etapa.

Para el proyecto final del curso comenzamos a trabajar con HTML y CSS, incorporando nuevas herramientas para el diseño y la organización de contenidos en una página web. De esta manera, este mismo portafolio forma parte del aprendizaje, reuniendo los trabajos realizados y explorando nuevas posibilidades de presentación e interacción digital.

02 / SEGUNDA UNIDAD

Introducción al front-end.

01 / CONTENIDOS

Diseño y desarrollo web

Durante la segunda unidad de Imagen Escrita comenzamos a trabajar en el diseño y desarrollo de sitios web, introduciéndonos al front-end y a los principios del diseño de interfaces de usuario (UI). A través de esta unidad conocimos la estructura de un sitio web estático y las funciones de HTML y CSS, comprendiendo cómo se organiza, etiqueta y presenta el contenido dentro de una página web.

También incorporamos nuevas herramientas de desarrollo, como Visual Studio Code y GitHub, para trabajar con los archivos, organizar nuestros proyectos y publicarlos en internet.

02 / ENCARGO DE CIERRE

Portafolio web personal

Como encargo de cierre de la unidad, desarrollamos un portafolio web personal y funcional. Para comenzar, realizamos un wireframe inicial que nos permitió organizar los contenidos y definir la estructura visual del sitio.

Posteriormente trabajamos en la modificación del código HTML y las propiedades CSS, adaptando la distribución, las tipografías, los colores y otros elementos gráficos a nuestra propuesta de diseño.

TRABAJO DE CIERRE · UNIDAD 2

Portafolio web.

El proyecto final de Imagen Escrita 2026 corresponde al desarrollo de este portafolio web personal, realizado mediante HTML y CSS en Visual Studio Code y publicado a través de GitHub Pages. El sitio reúne los ejercicios, proyectos y procesos desarrollados durante el curso, organizados en una estructura que permite recorrer los contenidos de ambas unidades.

Su diseño se construyó a partir de un wireframe inicial, definiendo una propuesta visual propia mediante el uso de tipografías, colores, fotografías y elementos de navegación. De esta manera, el portafolio no solo funciona como un archivo de los trabajos realizados, sino que también representa el resultado del aprendizaje adquirido durante la segunda unidad.
